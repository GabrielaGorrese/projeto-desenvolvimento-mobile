# Projeto Mobile - React Native (Expo)

## Stack
- React Native com Expo
- React Navigation
- Arquivos .jsx para telas, lógicas e componentes

## Estrutura
- src/assets/: imagens, mídias, ícones, etc.
- src/components/: componentes reutilizáveis
- src/navigation/: lidar com navegação
- src/screens/: telas do aplicativo

## Conversão de Figma para React Native
- Frame → View
- Auto Layout → Flexbox
- Text → Text
- Componentes repetidos → criar componentes reutilizáveis

## Padrões de UI
- Usar StyleSheet
- Evitar inline styles
- Componentes reutilizáveis sempre que possível

## Convenções
- Nomes em inglês
- Componentes em PascalCase
- Hooks em camelCase

## Objetivo
Gerar telas baseadas em designs do Figma mantendo consistência visual e reutilização de componentes.
